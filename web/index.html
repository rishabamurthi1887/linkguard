Privacy, in plain language

Local checks run first. If a supported provider is configured, your separate opt-in sends the full link, including its path and query, to that provider for reputation lookup. Do not opt in for private or sensitive links. Message text is processed in memory and is not saved; file bytes are processed in memory and not retained.
